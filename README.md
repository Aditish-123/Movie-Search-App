# 🎬 Movie Search App

A simple and responsive movie search website built using HTML, CSS, and JavaScript.

The application allows users to search for movies and view basic
information such as movie rating and release year.

## ✨ Features

- 🔍 Search movies by name
- 🎬 Display movie cards
- ⭐ Show movie ratings
- 📅 Show release year
- 📱 Responsive design
- 🎨 Simple and clean user interface
- ❌ Shows a message when no movie is found

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript

## 🎥 Movies Included

The demo includes movies such as:

- Avengers
- Inception
- Interstellar
- Avatar
- Titanic
- Joker

## 🚀 How to Run

1. Download or clone this repository.
2. Open the `Movie-Search-App` folder.
3. Open `index.html` in a web browser.
4. Enter a movie name in the search box.
5. Click the Search button.
